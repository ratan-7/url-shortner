# url-shortner

A scalable URL shortening and link analytics platform built to explore backend engineering, system design, caching, database optimization and performance engineering.

## Project Goals

- URL shortening and redirection
- Guest and registered user support
- Custom URL aliases
- Advanced click analytics
- Redis caching
- Background job processing
- Load testing and performance optimization

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Redis
- BullMQ
- Docker
- Nginx
